# Cortex Remote

코텍스 리모트(Cortex Remote)는 iPad·iPhone의 브라우저에서 Neural DSP Quad Cortex의 프리셋과 씬을 편집하는 비공식 웹 앱입니다. Windows PC 또는 리모트 디바이스(Raspberry Pi)가 USB로 본체와 통신하고, Safari는 로컬 네트워크를 통해 편집 화면을 표시합니다.

긱뷰에서 씬 타일의 연필로 이름과 색상을 편집합니다. 타일을 다른 씬으로 드래그하면 서로 교환하고, Alt를 누른 채 놓으면 대상 씬에 복사합니다. iPad에서는 원본 씬의 ⇄를 누르고 대상 씬을 탭해 복사할 수 있습니다. 프리셋 저장 버튼으로 변경 사항을 저장하세요.

## 배포 파일 받기

**현재 시험 버전은 v0.6.1입니다. 정식 출시 전에는 v0.x.y를 유지합니다.**

- **패치** — 버그 수정이나 작은 UI 개선을 배포할 때 마지막 숫자를 올립니다. 예를 들어 v0.0.1 다음은 v0.0.2입니다.
- **마이너** — 새 편의 기능을 배포할 때 가운데 숫자를 올리고 마지막 숫자를 0으로 돌립니다. 예를 들어 v0.0.2에서 v0.1.0으로 올립니다.
- **메이저** — 첫 정식 출시 버전은 v1.0.0입니다. 이후에는 리모트에 AI를 도입하는 등 제품 사용 방식이 크게 달라질 때 첫 숫자를 올립니다.

| 하려는 일 | 공개될 파일 |
| --- | --- |
| [새 SD 카드 설치](#install-sd) | `cortex-remote-v0.6.1-pi-zero2w-arm64.img.xz` |
| [기존 리모트 디바이스 업데이트](#update-pi) | `cortex-remote-v0.6.1-update.zip` |

출시 후 이 표에서 설치 파일을 바로 받을 수 있습니다. 두 파일과 검증용 `SHA256SUMS`는 [GitHub Releases](https://github.com/Hamsang13/cortex-control-mobile/releases)에 함께 게시됩니다.

## 처음 설치 · microSD 이미지

**Raspberry Pi Zero 2 W/WH**, 8GB 이상 microSD, 안정적인 5V 전원, USB OTG 어댑터와 Quad Cortex용 USB 데이터 케이블을 준비하세요. Mac과 Windows는 같은 이미지를 사용합니다.

1. 배포 파일 `cortex-remote-v0.6.1-pi-zero2w-arm64.img.xz`를 받습니다. `SHA256SUMS`와 대조할 때는 Mac에서 `shasum -a 256 파일명`, Windows PowerShell에서 `Get-FileHash 파일명 -Algorithm SHA256`을 사용하세요.
2. 컴퓨터의 카드 슬롯 또는 USB 카드 리더기에 microSD를 연결합니다. **기록하면 선택한 카드의 기존 데이터가 모두 지워집니다.** Raspberry Pi Imager에서 Zero 2 W → 운영체제 **사용자 이미지(Use custom)** → 다운로드한 `.img.xz` → 대상 카드를 선택하세요. OS 사용자 설정은 건너뛰고 기록과 검증이 끝날 때까지 기다립니다. XZ 압축 이미지를 지원하는 다른 SD 기록 도구도 사용할 수 있습니다. [Raspberry Pi Imager 공식 안내](https://www.raspberrypi.com/documentation/computers/imager.html)
3. 무선 국가 기본값은 한국(`KR`)입니다. 다른 국가에서 사용할 때는 기록된 카드의 **bootfs → cortex-country.txt**에 해당 두 자리 국가 코드를 저장합니다. 카드를 안전하게 꺼내 리모트 디바이스에 넣습니다.
4. Quad Cortex에는 자체 전원을, 리모트 디바이스에는 **PWR IN**으로 5V를 공급합니다. 리모트 디바이스의 **USB** 데이터 단자와 Quad Cortex의 **USB-B**를 OTG 어댑터와 데이터 케이블로 연결하세요.
5. iPad의 Wi-Fi 목록에서 **Cortex-Remote-Setup**에 연결합니다. 최초 설정 전용 비밀번호는 **CortexSetup1**입니다. 가까이 있는 사용자가 먼저 등록할 수 있으므로 개인 공간에서 한 대씩 설정하세요. 인터넷이 없는 네트워크에 계속 연결한 상태로 Safari에서 **http://10.42.0.1:8765/** 를 엽니다.
6. 최초 설정은 영어로 열립니다. 오른쪽 위 지구본에서 한국어를 선택할 수 있습니다. 리모트에서는 **Device Settings → Language**에서 변경합니다. 선택은 같은 브라우저와 접속 주소에 저장되며, 최초 설정, 설정 창, 상단 연결 상태 및 USB 연결 안내에 적용됩니다.
7. 개인 핫스팟 이름과 Wi-Fi 비밀번호를 저장합니다. iPad를 새 Wi-Fi에 연결하고 **Cortex Remote 열기**를 누르세요. 직접 접속할 기본 주소는 `http://10.42.0.1:8765/`입니다. 외부 Wi-Fi용 키는 자동 생성되며 설정 완료 화면에서 펼쳐 확인할 수 있습니다.

개인 핫스팟에 연결된 기기는 Wi-Fi 암호만으로 리모트를 조작할 수 있습니다. Wi-Fi 안내 화면의 **리모트 주소 복사** 버튼은 키 없는 주소를 복사합니다. 공유기나 휴대폰 핫스팟을 통해 접속할 때는 기존 웹 접속 키를 사용합니다. **다음 연결부터 이 기기에서 표시하지 않기**를 선택하면 같은 Wi-Fi 주소를 쓰는 iPad에만 적용됩니다. 다시 표시하려면 리모트 핫스팟 IP의 **http://10.42.0.1/** (주소를 바꿨다면 변경한 IP)를 열어 선택을 해제하세요. iPad의 비공개 Wi-Fi 주소가 바뀌면 새 기기로 인식합니다. 기존 설치에는 소스에서 `sudo bash source/release/install-welcome.sh`로 안내 서비스를 설치하고 다음 핫스팟 시작부터 사용합니다.

Quad Cortex를 USB로 연결하기 전에는 연결 안내가 표시됩니다. 이때도 톱니바퀴에서 네트워크 설정과 앱 업데이트를 사용할 수 있습니다. 연주 중 USB가 빠지면 편집을 잠그고, 다시 연결되면 본체의 현재 프리셋과 씬으로 돌아갑니다. 수동으로 USB를 해제했다면 **USB 연결**을 눌러 재개하세요.

이미지에는 OS, 앱과 ARM64 USB 의존성이 들어 있습니다. 첫 부팅은 인터넷·SSH·터미널 없이 진행되며, 이후에는 개인 Wi-Fi와 앱이 자동으로 시작됩니다. 설치용 비밀번호는 공개값이고 개인 Wi-Fi 비밀번호와 접속 키는 각 카드의 최초 등록 때 결정됩니다. 이미지의 SSH 로그인은 꺼져 있습니다.

## 설치 후 · Wi-Fi로 업데이트

1. 인터넷에 연결된 PC 또는 iPad에 `cortex-remote-v0.6.1-update.zip`을 미리 저장합니다. iPad에서는 파일 앱의 **나의 iPad** 등에 실제 다운로드를 완료하세요.
2. 해당 기기를 리모트 디바이스의 개인 Wi-Fi에 연결하고 기존 즐겨찾기로 리모트를 엽니다.
3. 기기명 옆 **⚙ → 리모트 디바이스 → 오프라인 앱 업데이트**에서 받은 ZIP을 그대로 선택해 **업데이트 적용**을 누르세요. 적용 중에는 리모트 디바이스 전원을 유지합니다.
4. 서명과 파일 해시가 맞으면 앱을 다시 시작하고 기동 확인 후 브라우저가 새로고침됩니다. 손상된 ZIP은 설치 전에 거부합니다. 후보 앱이 시작되지 않거나 기동 점검을 통과하지 못하면 직전 앱으로 복귀합니다. **Wi-Fi, 접속 키, 사용자 설정과 캐시는 유지**됩니다. 일반 앱 업데이트에는 리모트 디바이스 재부팅이나 SD 카드 교체가 필요 없습니다.

리모트 디바이스 자체의 Wi-Fi 이름·비밀번호·접속 URL·키를 변경할 때는 같은 설정 화면에서 저장 후 리모트 디바이스를 재부팅하세요. 저장한 탭이 새 서버를 확인하면 이동합니다. Wi-Fi 정보가 바뀌면 iPad의 Wi-Fi 설정에서 새 네트워크에 먼저 연결하세요.

### iPad의 인터넷 연결과 리모트 디바이스의 외부 Wi-Fi

| 현장 네트워크 | 연결 방법 |
| --- | --- |
| 공유기 또는 휴대폰 핫스팟 사용 가능 | 리모트 디바이스와 iPad를 같은 네트워크에 연결합니다. 인터넷은 공유기·휴대폰이 두 기기에 직접 제공합니다. 두 기기 사이의 통신이 허용돼야 Wi-Fi 리모트가 열립니다. |
| 리모트 디바이스 자체 핫스팟만 사용 | iPad에서 리모트 디바이스를 직접 제어합니다. 리모트 디바이스에 인터넷 회선이 없으면 iPad에도 이 Wi-Fi를 통한 인터넷이 없습니다. |
| iPad가 다른 Wi-Fi에 계속 연결되어야 함 | Bluefy에서 BLE로 리모트 디바이스를 제어합니다. 리모트 디바이스의 온라인 업데이트에는 리모트 디바이스 자체의 인터넷 연결이 필요합니다. |
| iPad가 리모트 디바이스 핫스팟에 붙은 채 인터넷도 사용 | 리모트 디바이스에 별도 인터넷 업링크와 인터넷 공유가 필요합니다. 내장 Wi-Fi 하나를 사용하는 현재 설정은 AP와 외부 Wi-Fi 접속 사이를 전환합니다. |

1. 리모트 디바이스 핫스팟에서 **설정 → 연결 방식 → 핫스팟**에 공유기 또는 휴대폰의 2.4GHz WPA2 네트워크 이름과 비밀번호를 입력합니다.
2. **이 Wi-Fi에 연결**을 누른 뒤 iPad도 같은 Wi-Fi로 옮깁니다. 화면에 표시된 리모트 디바이스의 `.local` 주소로 이동합니다. 자동 이동이 어려우면 표시된 주소에 기존 `/#접속키`를 붙여 여세요.
3. **90초 안에 설정 → 연결 방식 → 핫스팟 → 연결 유지**를 눌러 저장합니다. 확인하지 못하거나 외부 Wi-Fi가 끊어지면 리모트 디바이스는 핫스팟 복구를 시도합니다. 게스트망·일부 휴대폰의 기기 간 격리 설정은 Wi-Fi 리모트 접속을 막을 수 있습니다.

### 업데이트 설치와 배포 권한

기존 리모트 접속 키로 업데이트를 설치하고 네트워크 설정을 변경할 수 있습니다. 배포 서명 키는 GitHub 배포 절차에서만 사용합니다. 시험 빌드는 main에서 자동 서명하며, 정식 배포는 저장소 소유자의 승인이 필요합니다.

v0.2.0 이전 설치에는 검증기 이전이 한 번 필요합니다. 아래 배포자 안내의 이전 절차를 완료한 뒤 온라인 또는 오프라인으로 업데이트하세요. 새 이미지는 처음부터 서명된 빌드 순서와 채널을 검사합니다. [기존 설치 이전](source/release/README.md#기존-설치의-보안-이전)

### GitHub에서 앱 업데이트

공식 서명 업데이트 채널에서 시험 빌드를 제공합니다. 처음 한 번은 이 기능을 포함한 서명 ZIP을 기존 앱에서 설치합니다. 이후 **설정 → 리모트 디바이스**를 열면 리모트 디바이스가 GitHub의 빌드를 확인합니다. **업데이트 설치**를 누르면 리모트 디바이스가 ZIP을 받아 검증하고 앱을 재시작합니다. 같은 버전의 시험 빌드는 빌드 번호로 구분합니다. 인터넷이 없으면 기존 오프라인 ZIP 절차를 사용하세요. [배포 채널 설정과 BLE 최초 설치](source/release/README.md#github-서명-업데이트-채널)

### ZIP 업로드 메뉴 또는 네트워크 서비스가 없는 기존 리모트 디바이스

기존 설치 계정으로 리모트 디바이스를 인터넷에 연결하고 아래 절차를 **한 번만** 실행합니다. 기존 접속 정보를 유지하면서 업로드 기능과 복구용 실행기를 설치합니다. 이후부터 ZIP을 사용하세요.

```sh
cd ~/cortex-control-mobile
git pull --ff-only origin main
bash source/install-pi.sh
```

## 블루투스 웹 시험판

처음 열면 그리드가 보입니다. 설정 → 연결 방식에서 오프라인(기본), 핫스팟, 블루투스를 선택합니다. 세 모드 모두 같은 GRID, DIRECTORY, GIG VIEW와 파라미터 에디터를 사용합니다. iPad에서는 Bluefy에서 신뢰된 HTTPS 리모트 주소를 열고 리모트 디바이스에 BLE로 연결합니다. 리모트 디바이스에는 같은 버전의 시험용 BLE 서비스가 필요합니다. [준비 및 검증 방법](source/ble-test/)

## 배포자 · 패키지 재생성

개발 소스는 [source/](source/)에 있습니다. [배포 빌드와 검증 절차](source/release/README.md)에 고정된 OS 원본, 서명 키 관리, ZIP 생성, 이미지 빌드, 가상 부팅 시험과 GitHub Releases 첨부 파일 목록이 있습니다.

## 사용 라이브러리

| 패키지 | 버전 | 역할 |
| --- | --- | --- |
| [pyquadcortex](https://github.com/stokes-audio/pyquadcortex) | 0.40.0 | Quad Cortex와 USB로 통신해 프리셋·씬·블록을 편집하고 본체 튜너가 측정한 음정(Hz)을 수신합니다. |
| hid | 1.0.9 | pyquadcortex가 USB 연결 시 hid.Device()를 호출합니다. 리모트 디바이스에서 로드하는 네이티브 라이브러리는 libhidapi-hidraw.so.0입니다. |
| protobuf | 7.36.2 | USB 통신 메시지를 직렬화·역직렬화합니다. 리모트의 I/O 설정 화면도 MessageToDict()로 본체 응답을 변환합니다. |
| [react, react-dom](https://github.com/facebook/react) | 각각 19.3.1 | 그리드, 파라미터 편집기, Gig View를 브라우저에 렌더링합니다. |

튜너 음정과 레벨 미터는 Quad Cortex가 측정한 값을 USB HID로 받아 표시합니다. 상단에는 아날로그 IN 1·2와 OUT 1~4를 각각 표시합니다. 그리드 포트 아래에서는 해당 라우팅의 레벨을 표시합니다. 여러 채널을 사용하는 포트는 가장 높은 레벨을 표시합니다.

배포자는 Python `cryptography`로 업데이트 ZIP에 서명하고, 리모트 디바이스는 이미지에 포함된 OpenSSL로 서명을 검증합니다. HTTP 서버는 Python 표준 라이브러리의 `http.server`를 사용합니다. 프런트엔드 번들 생성 도구는 [esbuild](https://github.com/evanw/esbuild) 0.28.2입니다.

USB 연결 후 My Presets가 도착하면 초기 로딩이 끝납니다. 다른 대분류는 백그라운드에서 계속 수집합니다.

I/O Settings를 열면 입출력, EXP 1·2, USB, MIDI, 헤드폰과 Global EQ의 본체 변경을 실시간으로 반영합니다.

### Zero 2 W USB 연결

새 SD 이미지와 소스 설치 스크립트는 USB 호스트에 `dwc2`를 설정합니다. 기존 설치에서 튜너는 동작하지만 그리드가 모델 정보를 기다리는 경우, 최신 소스에서 `sudo bash source/release/configure-usb-host.sh`를 실행하고 Pi를 한 번 재부팅하세요. `lsusb -t`의 루트 허브에 `Driver=dwc2/1p`가 표시됩니다.

### 선택형 1.9인치 LCD

Waveshare ST7789 170×320 모듈을 가로로 사용합니다. BCM 기준 SPI0 MOSI 10, CLK 11, CE0 8, DC 25, RST 27, BL 18을 사용합니다. 물리 핀은 VCC 1(3.3V), GND 6, DIN 19, CLK 23, CS 24, DC 22, RST 13, BL 12입니다. [Waveshare 모듈 문서](https://www.waveshare.com/wiki/1.9inch_LCD_Module)

리모트를 v0.5.0 이상으로 업데이트하고 저장소에서 `sudo bash source/release/install-lcd.sh`를 한 번 실행합니다. SPI가 꺼져 있으면 스크립트가 활성화하며 다음 부팅부터 적용됩니다. LCD 서비스는 이후 부팅마다 자동 시작합니다. 표시기만 갱신할 때도 같은 스크립트를 사용합니다. 시스템 Python의 Pillow, spidev, lgpio와 나눔고딕 폰트를 사용합니다.

LCD의 기본 SPI 속도는 250 kHz입니다. 배선에 맞춰 속도를 높이려면 `sudo systemctl edit cortex-lcd`의 `[Service]` 아래에 `Environment=QC_LCD_SPI_HZ=4000000`을 지정하고 `sudo systemctl restart cortex-lcd`를 실행합니다. 색 줄이 보이면 값을 250000으로 되돌릴 수 있습니다.

화면은 가로 320×170으로 그려 90도 회전해 전송합니다. 시계는 Pi의 시스템 시각과 시간대를 따릅니다. 인터넷과 배터리 백업 시계가 없는 상태에서 전원을 오래 꺼 두면 시각을 다시 맞춰야 할 수 있습니다.

대기 화면은 Pi 가동 시간, 로컬 시각, 리모트 실행 여부와 USB·신호 대기 상태를 표시합니다. 리모트가 실행 중이고 Quad Cortex가 USB로 응답하면 튜너와 물리 IN 1·2, OUT 1~4를 표시합니다. 연주를 멈춰도 화면을 유지하며, 0.5초 이상 새 샘플이 없는 값만 비웁니다. USB 연결이나 리모트가 끊기면 대기 화면으로 돌아갑니다. 튜너 마커는 가장 가까운 음과의 편차를 1센트 단위로 반올림해 ±3센트 이내는 초록, ±15센트 이내는 주황, 그 밖은 빨강으로 표시합니다. HID 정규화 값 0~1은 −40~0 dB에 대응하며, 0.85(−6 dB)부터 노랑, 1 이상에서 끝부분이 빨강입니다. 수신 패킷 카운터와 실제 변경 픽셀의 HID 수신→SPI 전송 완료 시간은 `/run/cortex-lcd/status.json`에 10초마다 기록합니다.
