# Cortex Remote 다운로드

v1.0.0은 공개 전입니다. 공개 후 [GitHub Releases](https://github.com/Hamsang13/cortex-control-mobile/releases)에서 버전을 열고 **Assets**에서 용도에 맞는 파일을 받으세요.

| 하려는 일 | 받을 파일 |
| --- | --- |
| 새 microSD로 처음 설치 | `cortex-remote-v1.0.0-pi-zero2w-arm64.img.xz` |
| 기존 Pi의 앱을 Wi-Fi로 업데이트 | `cortex-remote-v1.0.0-update.zip` |
| 다운로드한 파일의 무결성 확인 | `SHA256SUMS` |

Mac과 Windows는 같은 이미지를 사용합니다. GitHub의 **Source code (zip)**에는 개발 소스가 들어 있습니다. SD 기록, iPad 첫 접속, 업데이트 순서는 [설치 안내](../README.md)를 참고하세요.
